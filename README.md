# LingoPulse — Site English Learning

Version indépendante du projet d’apprentissage de l’anglais.

## Démarrage

Le site est une application statique autonome. Ouvrez `dist/index.html` dans un navigateur ou servez le dossier `dist` avec un hébergeur statique.

## Déploiement

Le contenu de `dist` peut être déployé sur GitHub Pages, Netlify, Vercel, Cloudflare Pages ou tout autre hébergeur de fichiers statiques.

## Contenu actuel

- tableau de bord et progression ;
- niveaux A1 à C2 ;
- verbes avec recherche et audio ;
- grammaire et quiz ;
- flashcards de vocabulaire ;
- prononciation ;
- expression orale ;
- compréhension orale avec transcription ;
- anglais professionnel ;
- préparation aux entretiens.

La version actuelle utilise des données locales de démonstration. La lecture audio sélectionne en priorité une voix anglaise disponible dans le navigateur, avec un débit ralenti pour la prononciation. Pour obtenir exactement la même voix sur tous les appareils, il faudra plus tard intégrer des fichiers audio enregistrés ou un service TTS avec licence.
